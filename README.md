# ออกหนังสือรับรอง 50 ทวิ — เวอร์ชันออฟไลน์ (ฟรี)

กรอกแล้วพิมพ์หนังสือรับรองการหักภาษี ณ ที่จ่าย (50 ทวิ) ได้ทันที ไฟล์เดียว ไม่ต้องติดตั้งโปรแกรม ไม่ต้องต่ออินเทอร์เน็ต

## ⬇ ดาวน์โหลด

**[ดาวน์โหลด tawi50-offline.html](https://github.com/wannisakarn/tawi50-offline/releases/latest/download/tawi50-offline.html)**

แม่แบบ Excel สำหรับออกทีละหลายใบ: [tawi50-import-template.xlsx](https://github.com/wannisakarn/tawi50-offline/blob/main/tawi50-import-template.xlsx) (หรือกดปุ่ม “ดาวน์โหลดแม่แบบ Excel” ในโปรแกรมก็ได้)

อยากลองใช้แบบออนไลน์ก่อน: https://tawi50.vercel.app

## ทำอะไรได้บ้าง

- คำนวณภาษีหัก ณ ที่จ่าย 1% / 2% / 3% / 5% ฯลฯ และเขียนจำนวนเงินเป็นตัวอักษรให้
- ตรวจเลขประจำตัวผู้เสียภาษี / บัตรประชาชน 13 หลัก
- จำรายชื่อผู้รับเงิน และรันเลขที่เอกสารต่อให้
- พิมพ์ฉบับที่ 1–2 หรือ Save as PDF
- **ใหม่:** นำเข้าจาก Excel แล้วออก 50 ทวิทีละหลายใบ และพิมพ์ทั้งชุด
- **ใหม่:** ส่งออกไฟล์สำหรับทำ ภ.ง.ด.3 / ภ.ง.ด.53 ได้ทั้งไฟล์ .txt สำหรับโปรแกรม RD Prep, ไฟล์ Excel และไฟล์รูปแบบกลาง (Format กลาง) ภ.ง.ด.53 V2.0
- **ใหม่:** สำรองข้อมูลเป็นไฟล์ .json แล้วนำเข้าที่เครื่องอื่นได้

## วิธีติดตั้ง

1. กดลิงก์ดาวน์โหลดด้านบน ถ้าเบราว์เซอร์ถาม ให้กด “เก็บไว้ / Keep”
2. ย้ายไฟล์ไปไว้ในโฟลเดอร์ที่หาง่าย เช่น เอกสาร › บัญชี
3. ดับเบิลคลิกไฟล์เพื่อเปิด แนะนำให้ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ ถ้าไฟล์เปิดในโปรแกรมอื่น ให้คลิกขวา › Open with › Google Chrome
4. ถ้าต้องการ ให้สร้างทางลัดบนหน้าจอ โดยคลิกขวาที่ไฟล์ › Send to › Desktop (create shortcut) ถ้าเป็น Windows 11 ให้กด Show more options ก่อน

## วิธีใช้

**ออกทีละใบ**

1. กด “ล้างข้อมูลตัวอย่าง” แล้วกรอกข้อมูลบริษัทของคุณ (กรอกครั้งเดียว ระบบจะจำไว้)
2. กรอกผู้รับเงิน ยอดเงิน ประเภทเงินได้ และอัตราภาษี
3. กด “บันทึกและพิมพ์”

**ออกทีละหลายใบจาก Excel**

1. กด “ดาวน์โหลดแม่แบบ Excel”
2. กรอกแถวละ 1 รายการจ่าย ถ้า “เลขที่” ซ้ำกัน ระบบจะรวมเป็นใบเดียว ดูวิธีกรอกแต่ละคอลัมน์ได้ในแผ่นงาน “วิธีกรอก”
3. เลือกไฟล์ในโปรแกรม ระบบจะตรวจข้อมูลก่อนนำเข้า ถ้ามีแถวที่ผิด จะบอกเลขแถวให้แก้
4. กด “พิมพ์ทั้งชุด”

**ทำ ภ.ง.ด.3 / ภ.ง.ด.53 สิ้นเดือน**

1. เลือกแบบ เดือน และปี แล้วตรวจยอดรวมที่แสดง
2. เลือกรูปแบบ “ไฟล์ .txt สำหรับโปรแกรม RD Prep” แล้วกดส่งออก
3. ในโปรแกรม RD Prep ไปที่เมนู “โอนย้ายข้อมูล” เลือกตัวคั่น `|` แล้วจับคู่คอลัมน์ ครั้งแรกครั้งเดียว จะได้ไฟล์ .rdx ไว้ยื่นทางอินเทอร์เน็ต
   - ถ้าภาษาไทยเพี้ยน ให้เลือกการเข้ารหัสเป็น ANSI แล้วส่งออกใหม่

## ความเป็นส่วนตัว

ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของเครื่องคุณเท่านั้น ไม่มีการส่งข้อมูลออกไปที่ไหน เพราะเปิดใช้งานได้แม้ไม่มีอินเทอร์เน็ต ควรเปิดด้วยเบราว์เซอร์เดิมทุกครั้ง และกด “สำรองข้อมูล” เก็บไว้เป็นระยะ
